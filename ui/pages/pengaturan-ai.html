info

Cara Mendapatkan API Key (Gratis):

  1. Buka Google AI Studio.
  2. Login dengan akun Google Anda.
  3. Klik tombol "Create API Key".
  4. Copy kunci tersebut dan paste di form bawah ini.

API Key Anda disimpan dengan aman dan hanya digunakan untuk fitur AI di akun Anda.
